MindCare — Manual Prediction Test Form

Decision-support model only — not a diagnostic tool. Every real prediction must go through psychologist review before reaching a patient. This page is a local manual-testing convenience for the running dev server (src/api/main.py); it is not part of the documented, deployed patient-facing product. The estimated severity tier and recommendation bundle shown after a prediction are a best-guess reconstruction from dataset templates, not clinical advice.
